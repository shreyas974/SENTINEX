Telemetry Integrity

Real-Time Population Stability Index (PSI) Drift Monitor

Empirical Bayes Laplace-Smoothed PSI

  • Calculates distribution shifts across sliding windows (W = 100 observations).
  • Bins reference Gaussian baseline CDFs into 5 quantile intervals.
  • Formulation: PSI = Σ (P_actual - P_expected) * ln(P_actual / P_expected).
  • Laplace pseudocount smoothing (α = 1.0) prevents zero-frequency instability in small streaming windows.
  • Channels Monitored: Gait Variance (kinematics), Acoustic dB (noise), Heart Rate (cardiac).
actual_pcts = (actual_counts + 1.0) / (N + 5.0)
psi = np.sum((actual_pcts - expected_smoothed) * np.log(actual_pcts / expected_smoothed))

Drift Classification & Automated Recalibration

  • STABLE (PSI < 0.10): Telemetry Health 90–100%. Dual-engine maintains full operational confidence.
  • WARNING (0.10 ≤ PSI < 0.25): Telemetry Health 60–89%. Environmental shift detected; widens conformal intervals.
  • CRITICAL SHIFT (PSI ≥ 0.25): Telemetry Health 20–59%. Severe domain shift; triggers automated model recalibration alert.
